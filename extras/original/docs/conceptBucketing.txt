TASK
Assign each CLAIM_ITEM to one or more buckets from BUCKET_CATALOG, then return results grouped by bucket (bucket → list of items).

- Do NOT invent buckets.
- If an item fits no bucket, place it under "OTHER_UNMAPPED".
- Buckets are intentionally broad; prefer recall over precision.

A) BUCKET_CATALOG (authoritative; use exact names)
{{BUCKET_CATALOG_TEXT}}

CLAIM_ITEMS:
{{CLAIM_ITEMS_TEXT}}

LABELING RULES (REASONING-OPTIMIZED)
1) Broad inclusion (recall > precision): include all buckets that reasonably apply.
2) Implied disease rule (critical):
   If item is procedure/drug/lab/device/visit AND it strongly implies a disease area,
   assign BOTH (a) the treatment/procedure/drug/lab/device/visit bucket(s) AND
   (b) the implied disease diagnosis bucket(s), if present.
3) Hierarchical disease buckets:
   If both a specific diagnosis bucket and a broader related diagnosis bucket exist, assign BOTH.
4) Multi-concept parsing:
   If item_name implies multiple independent concepts, assign all relevant buckets.
5) Visit buckets:
   Assign Inpatient_visit / Outpatient_visit / Emergency_department_visit when explicit or clearly implied.
